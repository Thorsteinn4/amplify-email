Why this is bulletproof

• Layout is tables with inline styles — the only thing email clients render reliably.
• The button is real HTML (a colored, padded link), not an image, so it never breaks or blurs.
• Dividers can be pure CSS, so there's one less image to host.
• Photos must be images. Host them where the file is served exactly as uploaded. WordPress re-encodes uploads to WEBP, which Outlook can't display and Gmail renders poorly. Any headshot on /wp-content/ will trip the warning above — move those to a clean host (a non-WordPress folder/subdomain, or a free Cloudinary account) and paste the new URL.
